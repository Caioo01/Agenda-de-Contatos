# 📒 Agenda de Contatos em Python

Programa de terminal para gerenciar uma agenda de contatos, desenvolvido como exercício prático durante meus estudos de Python.

## Funcionalidades

- Adicionar contato (nome, telefone, email e se é favorito)
- Visualizar todos os contatos cadastrados
- Editar nome, telefone, email ou status de favorito de um contato
- Favoritar um contato
- Deletar um contato
- Listar apenas os contatos favoritos

## Conceitos praticados

- Funções com e sem parâmetros
- Listas e dicionários (lista de dicionários)
- Laços `while` e `for`
- Estruturas condicionais `if`, `elif` e `else`
- Validação de entrada do usuário
- Métodos de lista como `append()` e `remove()`
- f-strings

Projeto feito para fins de estudo. 🐍
